The ReclaimLLM Enterprise LLM Gateway is a hosted, governed proxy for team LLM API traffic. Instead of developers holding provider API keys directly, applications point at the gateway and authenticate with a team-scoped gateway key — the gateway resolves that key to your org's provider credentials and model policy, forwards the request, and logs it back to your dashboard with full org/team attribution.

<Warning>
  The Enterprise LLM Gateway is an **enterprise-only feature**. [Contact the ReclaimLLM team](https://reclaimllm.com/pricing#enterprise) to enable it for your organization.
</Warning>

## Why use it over the local proxy

The [Local API Proxy](/capture/api-proxy) runs on a developer's own machine using their own provider keys — it's individual capture. The Enterprise Gateway is the org-level equivalent: credentials live centrally, access is scoped per team, and every call is attributed and policy-checked before it reaches the provider.

## How to use it

Once an org admin has issued you a team gateway key, point your app at the gateway host and authenticate with the key as a bearer token — no other client changes needed for an OpenAI-compatible SDK.

```text
Base URL:  https://proxy.reclaimllm.com/<org-slug>/v1
Auth:      Authorization: Bearer <gateway-key>
```

Supported endpoints: `/v1/chat/completions` (streaming and non-streaming), `/v1/responses`, `/v1/embeddings`.

```bash
curl https://proxy.reclaimllm.com/acme/v1/chat/completions \
  -H "Authorization: Bearer rclm-gw-your-team-key" \
  -H "Content-Type: application/json" \
  -d '{"model": "openai/gpt-5.6-luna", "messages": [{"role": "user", "content": "hello"}]}'
```

<Note>
  Credential-related fields in the request body (`api_key`, `api_base`, `headers`, and similar) are always ignored — the gateway only ever forwards using the org's configured provider credentials, so a gateway key can't be used to redirect traffic to a different provider or endpoint.
</Note>

<Note>
  Request models must use a LiteLLM provider prefix (`openai/gpt-5.6-luna`, not bare `gpt-5.6-luna`). Org allowlists store the bare name. Full contract and exact `422` / `403` / `501` bodies: [Model naming contract](/enterprise/llm-gateway#model-naming-contract).
</Note>
