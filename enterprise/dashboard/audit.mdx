The Audit tab (`/enterprise/orgs/{org_id}/audit-log`) provides an immutable security ledger recording privileged actions and sensitive operations across your organization.

## What you'll see

- **Security ledger** — a chronological event log tracking every admin and system event with timestamp, actor, action, target, category, and outcome.
- **Event filters** — filter by date range, category (organization, identity, team, policy, security, credential, billing, sensitive_access), outcome (succeeded, pending, partial, failed), actor ID, and target type.
- **Detailed metadata** — expand any event to inspect request metadata, actor IP, affected resource IDs, and parameter payloads.
- **Export CSV** — export current filtered audit records for external compliance reporting or SIEM ingestion.

## What you can do

- Search and inspect security events across teams and members.
- Investigate policy modifications, membership updates, and API key creations/revocations.
- Review coverage security events such as `coverage.hooks_tampered`, `coverage.dlp_disabled`, `coverage.device_silent`, and `coverage.gateway_bypass`, plus policy events for coverage settings and DLP exceptions.
- Export audit log records as CSV for legal hold or security compliance reviews.
- Forward the same completed events to an external SIEM from the [SIEM tab](/enterprise/dashboard/siem).

## Who sees it

Admin only. Records are retained for 365 days.
