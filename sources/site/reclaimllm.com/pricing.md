FAQ

## Common questions.

### Is the free plan really free forever?

Yes. No credit card, no time limit. You get local proxy capture, hooks, browser capture, 200 stored sessions, full-text search, sharing, and up to 5 collections. The hosted Enterprise LLM Gateway is enterprise-only.

### How does the free trial work?

When you subscribe to the Paid plan, your first 3 months are completely free — no charge until day 91. You get full access to all Paid features immediately. Cancel any time before the trial ends and you won't be billed.

### What's the difference between Free and Paid?

The main upgrades are: unlimited session storage, encrypted raw session storage with a downloadable recovery key, AI-powered features (semantic search, session summaries, diff explanations), sensitive data detection, bulk export, data residency options, and full usage history.

### What does context management mean?

RCLM turns captured sessions into searchable working memory. You can find prior work, export context for a new assistant, and keep team AI activity visible instead of scattered across vendor-specific histories.

### What counts as a session?

A session is one continuous Claude Code or Gemini CLI agent run captured via hooks, one browser conversation, or one proxy request record. Local proxy and enterprise gateway traffic are stored as proxy sessions with request metadata, model, duration, and token counts when available.

### How does enterprise pricing work?

Enterprise starts at $10/seat/month with the first 3 months free. Larger teams can contact us for volume pricing, annual billing, deployment requirements, org-wide encrypted session storage, and Enterprise LLM Gateway rollout.

### How does encrypted session storage work?

Paid users can enable encryption for their own raw session details and download a recovery key once. Enterprise org admins can enable org-wide encryption and control whether admins and team leads can open encrypted member session details. Summary, stats, and search metadata continue to work without decrypting every full transcript.

### Can I self-host?

Yes. The server is open source and can run anywhere. Enterprise customers can run a supported deployment path inside their VPC. A fully packaged Helm-based on-prem offering is coming soon.

### How does the hooks session limit work on Free?

The local proxy and browser extension are unlimited on all tiers. The 200 session limit on Free applies to hooks-captured sessions stored in your account. Once you hit 200, older sessions are removed as new ones come in — unless you export and delete manually, or upgrade to Paid.
