The Sessions tab (`/enterprise/orgs/{org_id}/sessions`) is the raw session list every other tab's charts and tables link into.

## What you'll see

- A full filter bar — search, user, team, model, category (Fix/Feature/Performance), project, dataset, tag, session type (CLI / API Proxy / Browser Chat), and a date-range picker.
- A list of sessions with checkboxes, session title, user, and ingested-at timestamp.
- A running "N sessions loaded" counter.

## What you can do

Filter using any combination above — every filter is a URL parameter, so a filtered view is shareable/linkable. Load additional pages with **Load more sessions** (cursor-based, 50 per page).

<Note>
  Row checkboxes are present but there's no bulk action wired up to them yet, and per-session delete is disabled in the enterprise view.
</Note>

## Who sees it

Visible to any role with portal access. Which sessions a given viewer can actually see is governed by the org's [session sharing settings](/enterprise/dashboard/settings#session-sharing).

For the full drill-down workflow (metric → filter → session → transcript), see [Observability → Session drill-down](/enterprise/observability#session-drill-down).
