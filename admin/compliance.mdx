## Prepare audit evidence

<Steps>
  <Step title="Check control health">
    The **Control health** tab lists each RC-AI control with pass, fail, or n/a status, TSC mapping, and population and exception counts. Failed controls, like an overdue quarterly access review, are flagged.
  </Step>
  <Step title="View a control's population">
    Click **View population** to see the evidence entries behind a control. Entries contain no session content.
  </Step>
  <Step title="Log risk exceptions">
    Accept a known risk with **Request exception** in the **Risk exceptions** register.
  </Step>
  <Step title="Generate an evidence pack">
    In **Evidence & exports**, pick a period and click **Generate CSV pack**. Packs include a SHA-256 manifest so reviewers can verify nothing changed.
  </Step>
  <Step title="Run access reviews">
    Use **Create campaign** in **Access reviews** to review gateway keys, members, and API keys.
  </Step>
</Steps>

## Example: RC-AI-02 population

RC-AI-02 checks that sensitive reads are redacted before transmission. Opening **View population** shows a linked session, `b9b69a10-a7bc-46a4-8309-d9b99f31a381`, with status **new** and flagged **AD-004**:

| Fact | Value |
| --- | --- |
| **First seen** | Oct 14, 2026, 08:00 PM |
| **Access types** | read |
| **Matched patterns** | `.env` |
| **DLP gap** | 1 uncovered / 0 covered sensitive reads |

The DLP gap means one sensitive read happened that no policy covered. One click opens the session itself.

## FAQ

<AccordionGroup>
  <Accordion title="Is ReclaimLLM SOC 2 certified?">
    Not yet. ReclaimLLM's SOC 2 Type II is targeted for Q4 2026. The Compliance page helps you gather evidence about your own AI coding controls.
  </Accordion>
  <Accordion title="What is in an evidence pack?">
    CSV files for the period you pick, with a SHA-256 manifest so reviewers can confirm the files haven't changed.
  </Accordion>
  <Accordion title="What does a DLP gap mean in a population entry?">
    It counts sensitive reads that were not covered by a policy versus those that were. In the RC-AI-02 example, one .env read was uncovered.
  </Accordion>
</AccordionGroup>
