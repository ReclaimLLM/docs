## Get up and running

<Steps>
  <Step title="Create your free account">
    Sign up at [reclaimllm.com/register](https://reclaimllm.com/register) using GitHub or Google — no credit card required.
  </Step>
  <Step title="Grab your API key">
    Open **Settings → API Keys** in the dashboard and create your first key. The installer can open this page for you automatically.
  </Step>
  <Step title="Install and activate hooks">
    Run `pip install rclm` followed by `rclm-hooks-install`. The installer registers hooks for Claude Code, Gemini CLI, and Codex CLI, then saves your credentials locally.
  </Step>
  <Step title="Verify your first session">
    Start any Claude Code or Gemini CLI session. Open your RCLM dashboard — the captured session appears within seconds of the session ending.
  </Step>
</Steps>
