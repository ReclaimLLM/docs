## Triage signals

<Steps>
  <Step title="Find where issues concentrate">
    Start on the Signals overview. The **Projects × patterns** matrix shows which projects keep hitting the same problem, such as long idle gaps in sessions.
  </Step>
  <Step title="Filter anomaly reports">
    In **Anomaly reports**, filter by status, severity, or detector. Filter to **High** severity to triage what matters first.
  </Step>
  <Step title="Look up an anomaly code">
    Open any code in **What the anomaly codes mean** (AD-001 to AD-015). Each explains what it looks like, what an admin should do, and the guardrail to set.
  </Step>
  <Step title="Open the evidence">
    Click a matrix cell to jump to the evidence sessions behind it.
  </Step>
  <Step title="Act on each finding">
    Acknowledge, Resolve, Dismiss, Accept risk, or (for AD-015 external egress findings) **Mark destination safe** on each report.
  </Step>
</Steps>

## FAQ

<AccordionGroup>
  <Accordion title="What does AD-003 mean?">
    AD-003 is a runaway or looping session. The code detail explains what it looks like, the admin action, and the guardrail to set.
  </Accordion>
  <Accordion title="How do I see only the most important findings?">
    Filter Anomaly reports to High severity, then work through them with Acknowledge, Resolve, Dismiss, or Accept risk.
  </Accordion>
  <Accordion title="Can I get from a pattern to the actual sessions?">
    Yes. Click any cell in the Projects × patterns matrix to open the evidence sessions behind it.
  </Accordion>
</AccordionGroup>
