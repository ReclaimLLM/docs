Use the signed-in feedback workflow to report a bug, request a feature, or send a general comment.

## Submit feedback

Select the chat icon in the bottom-right corner of the application and choose the appropriate feedback type:

- **Bug Report**
- **Feature Request**
- **General**

Describe one issue or request clearly before submitting it.

<Note>
  You can submit one feedback item every seven days.
</Note>

## Track feedback

Open **Feedback** from the top navigation to view **My Feedback**. Each item shows:

- Its type
- Its current status
- The date it was submitted
- Your original message
- A note from the ReclaimLLM team, when one is available

If you have not submitted anything, the page shows an empty state and points you back to the chat icon.

## Include useful context

For a bug report, include the affected workflow, what you expected, what happened, and whether the issue is repeatable. Do not paste passwords, API keys, recovery keys, or unredacted sensitive session content into feedback.
